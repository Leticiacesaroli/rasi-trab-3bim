# rasi-trab-3bim

- PASSO A PASSO DO TRABALHO:

1. Criação e configuração da máquina virtual utilizando Ubuntu Server.
2. Configuração da rede e identificação do endereço IP da VM.
3. Configuração do acesso remoto por SSH.
4. Atualização do sistema e verificação do funcionamento do Docker.
5. Criação da aplicação web utilizando Python e Flask.
6. Criação do `requirements.txt` e do `Dockerfile` utilizando a imagem `python:3.14-slim`.
7. Construção da imagem Docker e execução do container com a aplicação Flask.
8. Teste da aplicação pelo navegador utilizando a porta 5000.
9. Expansão da aplicação com novas páginas, como `/sobre` e `/contato`, com diferentes títulos e layouts.
10. Reconstrução da imagem e realização dos testes finais das novas páginas.
